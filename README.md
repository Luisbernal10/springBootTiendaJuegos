# 🎮 Tienda de Video

Aplicación web desarrollada con **Spring Boot** que muestra un listado de videojuegos en formato de tarjetas (cards), usando **Thymeleaf** como motor de plantillas y **Bootstrap** para el diseño.

## 📋 Descripción

Este proyecto es un taller académico que consiste en construir una tienda de videojuegos simple, donde cada videojuego se muestra con su imagen, título, descripción y un botón de "Ver detalles".

## 🛠️ Tecnologías utilizadas

- **Java**
- **Spring Boot**
- **Maven**
- **Thymeleaf** (motor de plantillas)
- **Bootstrap 4** (diseño responsive)
- **HTML5 / CSS3**
